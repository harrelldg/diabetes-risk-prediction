# Data

Expected files:

- `Diabetes.csv`: training data.
- `Diabetes_test.csv`: held-out test data.

The official project brief describes the records as synthetically generated using statistical distributions inspired by real-world medical research. This preserves privacy while providing realistic health-pattern relationships for academic modelling.

Features cover demographics, lifestyle, family history, clinical measurements, diabetes stage, diagnosis, and a continuous risk score. The course brief lists the full data dictionary.

These synthetic records must not be replaced with identifiable healthcare data.
